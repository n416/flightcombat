# Yomimono Project Template

このリポジトリは、MDXベースのWeb小説・設定資料集の執筆および管理用テンプレートです。
ローカルでの快適な執筆環境と、外部小説投稿サイト（小説家になろう・カクヨム）への自動同期機能などを備えています。

## 主な機能
- **MDXベースの執筆**: Markdown拡張（MDX）により、ルビや用語リンクなどの独自タグをサポートします。
- **設定資料集（Wiki）機能**: プロット、キャラクター、世界観、年表などの設定を整理・閲覧可能なWebページとしてプレビューできます。
- **用語集・自動リンク**: 登録した専門用語を本文中に自動でリンク・注釈付けする機能（`npm run prepare-terms`）。
- **執筆・管理用UI（管理画面）**: 管理画面から、各エピソードの文字数カウントやビルド状況の確認が行えます。
- **自動投稿・同期**: 執筆したエピソードを「小説家になろう」や「カクヨム」にブラウザ操作なしで同期投稿・上書き更新可能です。
- **ファイル結合・出力**: 執筆した原稿をオフライン用のWordファイル（.docx）やプレーンテキストとして一括で結合・出力できます。

## セットアップ
1. Node.js がインストールされていることを確認してください。
2. 依存関係をインストールします。
   ```bash
   npm install
   ```

## 使い方

### 開発用サーバーの起動（プレビュー＆管理画面）
```bash
npm run dev
```
起動後、ブラウザで以下のURLにアクセスしてください。
*   **プレビュー画面**: `http://localhost:5173/`
*   **管理・同期画面**: `http://localhost:5173/admin`

### ファイル構成
執筆する原稿・設定ファイルは主に `public/settings/` ディレクトリに配置します。

*   `ep0010.mdx` 〜: 本編エピソード（連番）
*   `yomikiri.mdx`: プロローグ・短編用
*   `plot.mdx`: プロット
*   `character.mdx`: 登場人物設定
*   `world.mdx`: 世界観設定
*   `timeline.mdx`: 年表
*   `woodcraft.mdx`: 用語集・設定資料
*   `synopsis.txt`: アプリ・Word出力用のあらすじ

### 用語集・サイドバーの更新
新しいエピソードの追加や、用語辞書（`src/term_dictionary.js` 等）を更新した場合は、以下のコマンドでインデックスや用語マップを再生成します。
（`npm run dev` 実行前にも自動で走ります）
```bash
npm run prepare-terms
```

### 出力（エクスポート）
```bash
npm run build
```
ビルドを実行すると、自動的に各種原稿ファイルが結合され、プロジェクトルートにテキストファイルやWordファイル（`output_novel*`）が出力されます。

## 外部プラットフォームへの自動同期について
管理画面の同期ボタンや API 経由で「小説家になろう」「カクヨム」へ投稿を行うには、ブラウザの自動操作（Playwright）用のログインセッションデータを作成する必要があります。

初回利用時のみ、裏側で動作するブラウザ（Chromium）をインストールするコマンドを実行してください。
```bash
npx playwright install chromium
```

その後、以下のコマンドを実行します。
```bash
npm run login
```
上記のコマンドで専用のブラウザが立ち上がりますので、各サイトに手動でログインしてウィンドウを閉じることで、セッションがローカルに保存され、以降は全自動で同期できるようになります。（認証情報は `.gitignore` で除外されています）
